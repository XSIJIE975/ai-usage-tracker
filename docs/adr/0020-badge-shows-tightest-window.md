# macOS badge 数字改读最紧窗口

Status: accepted

修正 ADR-0017 的「badge 改绑外环百分比」：多层环落地后「数字与外环一一对应」的论证已名存实亡——三层嵌套下用户本就看不出数字对应哪根环，环层也没有逐层着色可用来指示对应关系。而多窗计量供应商（GLM Coding Plan v1 仅五小时窗、v2/v3 在五小时外加周窗、OpenCode Go 为五小时/周/月三窗）让「固定最短周期窗」在长窗更紧时失明：月窗已用 92%、5h 刚重置为 10% 时，菜单栏数字显示 10。

## Context

「读哪扇窗」此前有三个互不一致的口径并存（2026-09-10 代码核对）：

| 口径 | 用在哪 | 规则 |
| --- | --- | --- |
| 主指标 | 阈值告警、面板头指标（`extractMetric`） | 重置周期最长的窗（GLM=周、OpenCode=月） |
| 选例计分 | 托盘显示谁、排序（`candidate.percent`） | 全窗最大已用%（最紧窗口） |
| badge | macOS 数字（`badge_text`） | 入图三扇中周期最短的窗（外环） |

同一实例三个面各说各话。场景压测（用户 2026-09-10 诉求：单个数字无法应对各种计量方式的限制）：

| 场景 | 各窗状态 | 外环（现状） | 主指标 | 最紧窗 |
| --- | --- | --- | --- | --- |
| 周五晚 GLM v3 | 5h=20%、周=90% | 20 ✗ | 90 ✓ | 90 ✓ |
| 工作日 OpenCode Go | 5h=85%、周=40%、月=30% | 85 ✓ | 30 ✗ | 85 ✓ |
| 月末 OpenCode Go | 5h=10%、周=95% | 10 ✗ | 95 ✓ | 95 ✓ |

最紧窗口径全胜。它与外环口径只在「长窗比 5h 更紧」时分歧——那恰是现状出错的时候；工作日常态下 5h 通常就是最紧窗，两者重合，翻案的日常成本趋近于零。平手（两窗百分比相等）时沿用 `tightestWindow` 既有取法（窗口按重置近→远排序后取首个命中），落在重置更近的 5h 窗，与外环巧合、无跳变。

## Decision

**badge = 所选实例最紧窗口的已用百分比（全窗 max，与选例计分主键同源）：数字回答「离下一次撞限额还有多远」。**

1. **payload 显式契约**：`update_tray_meter` 新增可选参数 `badge_percent`，由 TS 端（持有全部窗口数据）声明；Rust 端只做取整与呈现指纹比对（ADR-0019），不再从 `ring_windows` 推断数字。不采用 Rust 端 `max(ring_percents)`：那依赖「最紧窗必入图」这条跨端不变量，仅靠注释维持，将来改截断规则时会静默出错。「最紧三扇入图」（ADR-0017 截断）仍然成立，但不再是数字正确性的前提。
2. **跳变是预期行为，不加设置项**：数字语义 = 紧急度，随最紧窗切换（如刷新后 12→95）是紧急度的真实变化；图标仍编码全部窗口，逐窗明细在 tooltip 与面板。「数字口径」设置项暂不做（YAGNI，有真实反馈再议）。
3. **其余一切不变**：层序/截断/环几何、柱方案不显示数字、告警口径（主指标 = 周期最长窗，防 5h 窗日常冲高噪音的刻意设计）全部维持。告警只盯主指标留下的盲区（OpenCode 月窗 30% 时 5h 冲满也不告警）记为后续项，与本题解耦。

## Considered Options

- **badge = 主指标（周期最长窗）**：与告警、面板头指标统一为单一概念，模型最简；但 5h 撞墙在即时数字失明（场景乙），且预算面的告警表达已由告警红承担，数字再押预算面没有增量信息。
- **维持外环、告警触发才切最紧窗**：平时稳定，但阈值（80%）之前的「接近未触发」区间仍失明，且两套语义叠加后规则难解释。
- **Rust 端取 `max(ring_percents)`**：零 payload 改动，见 Decision 1 的契约脆度否决。
- **「数字口径」设置项（最紧窗 / 外环）**：多一个口径的长期维护与认知成本，收益存疑，暂不做。

## Consequences

- 数字与面板头指标可能指不同窗口：分工是面板头指标 = 预算口径、badge = 紧急度口径；设置页「当前展示」的原因标注已写明最紧窗口，作为数字语义的落地解释。
- glossary「外环百分比」词条废除，「badge」「最紧窗口」词条随本题改写。
- 取整语义不变（Rust 端 round）；`badge_percent` 缺失（无候选实例、金额量纲、凭据库锁定）时数字为空，呈现指纹保证空数字不引发重绘。
