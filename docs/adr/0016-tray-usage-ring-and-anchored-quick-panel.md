# 托盘速览：图标方案体系与速览面板

Status: accepted

## Context

纯托盘模式下（主窗口关闭驻留，ADR-0015 之后还有静默自启）托盘图标是程序唯一的常驻表面，悬停只有一行静态提示，想瞄一眼用量只能唤快捷键面板或开主窗口。托盘左键原本绑定「toggle 快速面板」，但快速面板的形态（380px 全量卡片）不适合锚定托盘的轻量速览，且快速面板需收敛为纯快捷键/菜单入口。

平台事实（tray-icon 0.24.2 源码核实）：

- Enter/Move/Leave 悬停事件仅 Windows（WM_MOUSEMOVE 子类化）与 macOS（NSTrackingArea）有实现，Linux 无 hover 事件，与三平台对等冲突；悬停弹出另有误触、抢焦点、面板遮蔽图标的闪烁循环三个 UX 硬伤——否决。
- **DoubleClick 事件是死代码**：托盘窗口类注册时未设 `CS_DBLCLKS`（`WNDCLASSW { ..std::mem::zeroed() }`），`WM_LBUTTONDBLCLK` 永远不会到达。双击打开主窗口需自实现「两次抬起间隔 < GetDoubleClickTime」判定，且单击动作必须延迟一个双击间隔等待可能的第二击——单击零延迟与双击二者只能取一。
- Windows tooltip 限 127 字符纯文本；macOS 菜单栏图标无 tooltip；tray-icon 的 `set_title` 仅 macOS 非空实现。
- Linux 托盘事件坐标不可靠，锚定需兜底。

用户决策：否决双击打开主窗口（保留右键菜单为主窗口入口，换取单击零延迟弹面板）；速览面板全新布局、不与快速面板共用卡片；两种展示形态都做、面板内切换后再定去留；托盘图标改为可切换、可扩展的「方案」体系（替代单一用量环设想）。

## Decision

- **托盘交互**：左键单击弹出「速览面板」并锚定托盘图标旁，再点收起；右键菜单维持三项（打开主窗口 / 显示快速面板 / 退出）不变；快速面板由全局快捷键与右键菜单唤起、原位显示；悬停 tooltip 动态化为计量摘要，多行展示——首行实例名，其后每条配额窗口一行「窗口名（已用 N%）」，行序与用量柱上→下一致（Windows 端 LF 转 CRLF，szTip 总长仍守 127 字符；告警态沿用现有后缀）；macOS 无 tooltip，用 `set_title` 在图标旁显示百分比文本补齐。
- **速览面板**为全新独立窗口（label `glance`，无边框 / 置顶 / skipTaskbar / 失焦自动隐藏 / 高度自适应，宽约 320px），全新组件不与快速面板共用卡片；内置两种展示形态——紧凑行列表与迷你卡片环——面板头部切换、选择持久化；展示的实例范围与字段（余额、重置倒计时、多窗口明细、告警标记、顶栏刷新、底部通知条）在设置页配置。锚定：Windows 图标上方右对齐、macOS 菜单栏下方、Win11 溢出区 flyout 内点击回退工作区右下角、Linux 回退上次位置。
- **托盘图标方案体系**：图标呈现抽象为可切换、可扩展的方案，设置页选择、切换即生效。方案清单——「默认」（现有静态图标 + 告警换图）、「用量环」（环形进度）、「用量柱」（双横向胶囊条，参考 CodexBar 的双条用量指示器）。计量方案共用同一选择逻辑：默认最紧实例、可钉选（钉选选择器环/柱共用）；无可绘数据回退默认图标。配色为静态品牌色、不随用量档位变化，任一活跃告警强制红（档位变色只保留在速览/快速面板内）。方案在 Rust 侧光栅化（tiny-skia，无文字、零字体依赖），前端在刷新完成与告警态变化时推送主指标与告警态。不在前端 canvas 绘制：静默启动与关窗驻留下 webview 可能隐藏、渲染节流不可靠，而托盘恰恰必须照常工作。
- **用量柱**（后补方案）：两根横向胶囊条、上下堆叠、自左侧填充，上条 = 次指标、下条 = 主指标（通常周配额）——参考 CodexBar 的双条用量指示器；每条按各自百分比独立着色；实例仅一条配额线时单条居中（滚动窗口兜底）。取线与候选口径不依赖 resetsAt：GLM 滚动窗口的 nextResetTime 常缺失，候选判定改为「存在配额进度行」，次指标取主指标之外的第一条进度线（优先带 resetsAt 且重置最近的，否则按快照顺序）。次指标随计量快照一并推送（`update_tray_meter` 的可选参数），tooltip 按窗口逐行展示（见托盘交互）；macOS 数字标题仅用量环显示（柱方案图标已编码两个数值，不加字）。
- **自动选例规则**（后补细化，取代初版「最紧实例 = 主指标最高」口径）：候选 = 刷新成功且至少一条有效配额窗口行（余额类如 DeepSeek 无窗口出局，仅通过告警影响图标颜色；不要求 resetsAt，GLM 滚动窗口的 nextResetTime 常缺失）。显式钉选最高优先；自动先按实例列表「置顶」分组——有置顶候选时只在置顶集合内选（用户的主力名单，行为可预期）；组内排序 = 告警中优先 → 最紧窗口%（全部窗口的最大值）降序 → 全窗之和降序（"两扇都快用完"排在"只烧一扇"前）→ 列表顺序稳定兜底。展示一致性：环与 macOS 数字展示选中实例的最紧窗口（不再固定周期最长窗）；柱渲染该实例已用%最高的两个窗口（显示按重置近→远排，上短下长；OpenCode 三窗时月窗参与计分但不占柱位）；tooltip 逐行列出全部窗口。面板侧主指标口径（extractMetric）不受影响。

## Consequences

- 新增 Rust 依赖 tiny-skia；图标按 DPI 档位绘制（16/24/32px）。
- 新增一个常驻 webview（glance 窗口，启动即隐藏）；多窗口 store 不共享，需复制 quick 窗口的事件同步基建（settings-changed / instances-changed / alert-state-changed / refresh-completed 等）。
- `set_tray_alert` 的换图机制收编进「默认」方案；用量环方案下告警表达为环色 + 动态 tooltip。
- 设置页新增：托盘图标方案选择、钉选实例、速览面板实例范围与字段开关；面板形态在面板内切换并持久化。
- 双击打开主窗口被否决并留档：若未来重提，需先解决 tray-icon 缺 `CS_DBLCLKS`（自实现计时判定）与单击延迟（GetDoubleClickTime 防抖）两个前提。
