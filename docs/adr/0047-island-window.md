# ADR-0047: 灵动岛常驻胶囊窗口

状态：已接受　日期：2026-11-14　关联：ADR-0016、ADR-0019、ADR-0022、ADR-0023、ADR-0026

## 背景

借鉴开源项目岛仔 Daozai（github.com/Renly1994/xiaotang-daozai，MIT，Rust+egui）的灵动岛机制，为应用增加屏幕顶部常驻的额度氛围面：平时收起为胶囊（时钟 + 最紧额度环 + 告警点），鼠标悬停驻留展开为完整行列表，离开收起；与托盘速览互补——速览按需弹出，岛常驻可见，数据同源（同一快照与告警投影）不同呈现。

岛仔的机制在 egui/Win32 上成立，搬进 Tauri/WebView2 有一处架构性差异：岛仔用固定画布 + `SetWindowRgn` 控制可见区域、`WM_NCHITTEST`→`HTTRANSPARENT` 做命中区外点击穿透；而 WebView2 是子 HWND，鼠标消息直接进子窗口，父窗口 subclass 拦不到。

## 决策

**1. 固定画布永不 resize，展开/收起是画布内 DOM 形变。** 窗口固定 500×340 逻辑点（即展开态轮廓 + 投影余量），透明背景。展开/收起由前端弹簧动画驱动 morph 容器的宽高/轮廓/内容交叉淡入——对应岛仔「SetWindowRgn 只改区域不动窗口」的设计动机：避开 WebView2 逐帧 resize 的重排掉帧。透明窗口必须自绘轮廓（顶部肩部 + 底部圆角）与底色（不透明的 island fill 渐变），与不透明窗口「系统圆角勿自绘」的既有结论不冲突。

**2. 展开判定与点击穿透归 Rust 控制器，前端只负责视觉。** 独立线程轮询 `app.cursor_position()`（收起且无驻留 50ms，驻留/展开/动画期 16ms），驱驻留状态机（悬停 200ms 展开、离开 120ms 收起，参数对齐岛仔）；命中区（胶囊/面板矩形外扩边距，胶囊命中区向上延伸到画布顶）在 Rust 按常量计算。穿透用 `set_ignore_cursor_events` 整窗切换近似 HTTRANSPARENT：命中区外整窗穿透，光标进入命中区、展开态与切换动画期（450ms 窗口）保持可交互；状态去重后只在变化时调用窗口 API。事件 `island-expanded` / `island-collapsed` 通知前端跑动画，展开判定先解除穿透再发事件。

**3. 几何由控制器独占，不进 `panel_window::PANEL_LABELS`。** 定位 = 主显示器工作区顶部水平居中（物理像素，monitor scale 换算），每 1s 兜底校验纠偏（覆盖 DPI/分辨率/主屏变化，对齐岛仔 placement_at 模式）。`ensure_on_screen` 的工作区钳制与本定位互相打架，故不接入；岛窗口 `focusable: false`（永不抢焦点，点击不激活），`skipTaskbar` + `alwaysOnTop` + `shadow: false`。

**4. 数据接入复用速览面板的窗口基建，新增 `persistent` 模式。** `usePanelWindow({ persistent: true })`：跳过失焦自动隐藏与 Esc 收起（岛永不获焦，两者无意义），`panelVisible` 恒真使快照收敛（ADR-0019）照常回流；自动刷新由岛按 `islandEnabled` 自行门控——岛的 webview 在禁用时仍存活，不该驱动抓取（ADR-0023）。胶囊环复用 `UsageRing`、面板行复用 `GlanceRows`、数据推导复用 `buildGlanceInstances`。

**5. 展开动画用 JS 弹簧（`src/lib/spring.ts`，移植岛仔 anim.rs 的二阶阻尼 + 子步积分），刻意不用 CSS transition。** 本机 WebView2 恒报 `prefers-reduced-motion: reduce`，CSS 侧让步会让岛永远没有动画（styles.css `.panel-enter` 同类先例）；rAF 循环直接写 DOM、settled 即停，空闲零开销。

**6. 默认关闭 opt-in，开关走 invoke-then-save。** `islandEnabled` 存 settings blob（db.rs 逐键补默认），设置卡先 `set_island_enabled`（Rust 起停窗口与控制线程）成功后才落设置，失败不写库、开关弹回。静默启动（`--silent`）不拦岛：岛是 opt-in 的常驻面不是弹窗。macOS 透明启用 `macos-private-api`（自分发不走 App Store，无副作用）。

## 后果

- 状态机/命中矩形/定位公式/穿透决策全部是纯函数，Rust 单测锁定；弹簧数学与帧率无关性前端单测锁定。
- 窗口永不获焦的代价：岛上无文本输入（纯展示 + 按钮），键盘交互留给主窗口与快速面板。
- 悬停展开的判定依赖整窗穿透切换：切换瞬间存在极小概率点击竞态（一次点击被吞），展开判定先切 ignore 再发事件已把窗口压到最窄。

## P1 增补（同分支第二轮交付）

**7. 拖动换位存偏移比例。** 胶囊水平拖动：前端指针事件（4px 阈值区分点击）把逻辑位移增量喂 `drag_island_delta`，Rust 按当前屏 travel（`(工作区宽 - 画布宽)/2`）换算成 -1..1 比例并钳制，松手回存设置 `islandOffsetX`（换屏/改缩放按比例保持相对位置，画布不越屏）。拖动期间 `set_island_dragging` 抑制状态机展开（已在展开态则收起），松手清驻留计时防「早已悬停超时」立即展开。窗口位置只由控制线程写入，拖动生效延迟 ≤16ms（拖动时光标必在命中区，轮询自动升快采档）。

**8. 前台切换自动收起（仅 Windows）。** 主线程安装 `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)`（`WINEVENT_OUTOFCONTEXT` 要求安装线程泵消息，Tauri 主线程事件循环满足；回调只置原子位），控制线程消费：切到别的进程立即收起并锁定（对齐岛仔 hover_lock），光标离开命中区前不再自动展开。安装失败仅降级「切走不收起」。

**9. 全屏避让（仅 Windows）。** 控制线程每秒用 `GetForegroundWindow`+`GetWindowRect` 判定前台窗口矩形与岛所在屏整屏边界重合（最大化普通窗口是工作区、不会相等），进入即整岛隐藏、机器复位，退出恢复。其余平台无此判定，行为降级。

**10. 告警横幅 = 胶囊临时加宽。** 逐实例监听 `alert-state-changed` 激活边沿（anyAlert 的 false→true 会漏掉叠告警），胶囊宽度弹簧到 300 显示「实例名 · 额度告警」，6s 自动收回；命中区经 `set_island_banner_width` 随之放宽（Rust 侧钳在画布内），点击打开主窗口；展开面板时横幅取消（面板行已有告警呈现）。

## P2 增补（同分支第三轮交付）

**11. 面板形态可切换 + 告警横幅去重 + 浅色主题。** 展开面板支持 list/cards 两种形态（复用速览面板组件），设置项 `islandLayout`；告警横幅按实例去重（同实例本会话只弹一次）；岛专用主题 token `--island-fill-top/-bottom` / `--island-filter-shadow` / `--island-edge`，三套主题分支（浅色/深色/系统跟随）齐备——岛浮在桌面而非应用底色上，浅色主题需要比页面卡片更明确的描边。

**12. 侧边停靠。** 顶/左/右三态，靠拖动贴边自动切换（不设手动选项）：光标距目标边 ≤64px 且比当前边近 ≥24px、并已离开当前边吸附带 110px 才换边（岛本身贴边，光标天然离当前边很近，只比距离会误切）。左/右为竖向胶囊（40×96），展开面板向屏内伸出（424×284）；换边时窗口换画布尺寸（460×340 ↔ 500×600）。

**13. 拖动模型最终形态：贴边锚定 + 单轴 1:1 跟手。** 岛**永远贴边**，不允许浮到屏幕中间——顶部固定贴工作区顶只跟水平、侧边固定贴侧边只跟竖直。拖动期间位置由像素增量直接决定（起点原点 + 光标位移），不走弹簧、不按比例中转；松手才把位置反算成比例持久化。

**14. 拖动的三个实现级陷阱（代价最大的一轮修复）。**
- **`else if` 合并事故致松手分支不可达**：连续空块 `} else if dragging_prev { } else if dragging_prev {`，松手逻辑永不执行 → `target_offset` 不更新 → 下一拍常规定位把窗口拉回起点，表现为「沿边怎么拖都弹回原处、只能换边」。这类"语法合法但逻辑死掉"的重复块必须靠「拖动后位置是否真的变了」的行为测试兜住。
- **控制线程启动 1 秒内几何为全零**：`Geometry::default()` 使 travel 退化为 1.0 / 0，位置被钳到边缘端点。改为启动即读几何、几何无效时整拍跳过。
- **`end_island_drag` 竞态**：读的是松手前的旧比例（吸附要等下一拍），前端把旧值存回设置 → 重启后位置回退。改为按 `applied_origin` 直接回算。
  三处共同教训：**位置事实源必须唯一**（`applied_origin` 缓存 + 统一 `place_origin()`），换算口径也必须唯一（`travel_px()` 单一实现，所有几何函数共用）。

## P3 增补（同分支第四轮交付）

**15. 回归为单边：岛只从屏幕顶边长出来，侧边停靠整套撤除。** 侧边形态（竖向胶囊 + 向屏内滑出的面板 + 拖动换边）实测观感不佳——竖向胶囊在 40px 厚度里塞时间与额度环必然拥挤，面板朝屏内伸出时又缺少「贴着边缘」的形，读起来像一块卡在侧边的卡片。撤除后 `Dock` 枚举、侧边几何常量、换边判定、`get_island_dock` / `set_island_dock` 命令、竖排胶囊组件与 `islandDock` 设置项全部删除，`canvas_origin` / `travel_px` / `offset_from_desired` / `drag_target_origin` 退化为单轴（水平），`apply_canvas_size` 固定按 500×340 同步。**岛的位置只剩一个自由度：沿顶边的水平偏移。**

**16. 贴边形态：顶边齐平 + 顶部外翻肩部（不是圆角矩形）。** 原实现把 40px 高的胶囊浮在离屏幕顶 6px 处、四角全圆，读起来是「桌面上一颗胶囊」；只把顶部改成直角又会变成一块硬贴上去的方片。最终按岛仔 `shape.rs` 的几何重做轮廓（`src/components/island/shape.ts`，两端常量镜像）：
- 顶边与工作区顶边齐平（`PILL_TOP = 0`），且**顶边最宽**；两侧在 `flareH` 内沿 `wing = flare·(1-t)^2.4` 收敛到本体侧边——这段肩部让宽度向屏幕边缘张开，岛读作从边缘长出来。
- 尺寸对齐岛仔收起药丸（163×30）：胶囊总宽 160 × 高 32（含两侧 12×2 肩部，本体 136），底角半径 16（半圆）；展开轮廓 456×284（本体 424×284，肩部 16×2，底角 22，肩部/底角随形变插值）。
- 画布从 460 加宽到 500：轮廓总宽 456，两侧各留 22px 给投影，避免窗口边缘把阴影裁成方形残影。
- 表面不透明，用 `--island-fill-top/-bottom` 的极轻纵向渐变给肩部一点体积感；投影改用 `filter: drop-shadow` 跟随轮廓 alpha（box-shadow 画不出肩部）。
- 内容区按本体宽度内缩肩部宽度（收起 136、展开 424），底部圆角与轮廓同心；收起内容锚在顶部 32px，展开时不下坠。

**17. 描边必须画在内容之上，并且沿同一条轮廓（一处只有实测才发现的层级错误）。** `ring-1 ring-inset ring-island-edge` 写在 morph 上时，inset 描边属于元素背景层，而展开面板的内容是不透明的 `bg-canvas` 铺满整个容器——描边被整条盖住。逐像素核对截图：内容区最外侧一列就是纯 canvas 色（245），描边色（214）一个像素都看不到；只有标题栏那种半透明处才透得出来。修法是把描边作为最上层（`z-20`、`pointer-events-none`）的 SVG 路径，且用与表面同一条轮廓、内收 0.5px 后以 1px 描边绘制（描边完整落在表面内侧）；路径顶部敞开——顶边贴着屏幕边缘，画一条线会在屏幕顶上留一道缝。

## 后续（明确不做）

毛玻璃（WebView2 无系统模糊，需 DWM acrylic 或半透明底色近似）；前台切换收起与全屏避让在非 Windows 平台的等价机制；**侧边停靠**（P3 撤除，见决策 15——不是「还没做」，是不做）。

## 已知限制

- **分数缩放下的圆弧台阶**：150% 缩放下，近白面板贴在近黑壁纸上只有 1 设备px 抗锯齿，圆弧 45° 段每行挪 1px 就是一级台阶。这是 Chromium 在该对比度下的栅格化极限，只能削弱（1px 轮廓描边 + 极轻的表面渐变把一步拆成几级）不能消除。窗口本身没有任何几何误差（实测面板落在 x=27..662、y=9..434，正是 424×284 @1.5 的整像素位置）。
