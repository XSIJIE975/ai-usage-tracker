# 术语表（Glossary）

项目领域术语的唯一定义处。新增术语按字母/拼音序插入；定义与 ADR 冲突时以 ADR 为准并在此回链。

---

## 配额窗口（Quota Window）

provider 的一扇用量限制，如「5 小时请求配额」「每周请求配额」「本月额度」。快照行（`MetricLine` progress 行）是其数据载体：`percentUsed` + 可选 `resetsAt`。GLM 动态滚动窗的 `nextResetTime` 常缺失（ADR-0016）。

## 重置周期 vs 重置时刻（Window Duration vs Reset Time）

两个不同口径，禁止混用：

- **重置周期**：窗口时长（5 小时 / 一周 / 一月），provider 解析层结构化输出的静态属性。**环层序**的排序键（ADR-0017）。
- **重置时刻**（`resetsAt`）：下一次重置的时间点，动态值。**tooltip 行序与柱方案上→下**的排序键（ADR-0016，`compareWindowReset`）。

多数时候短周期窗重置更频繁、下一重置也更近，但不严格保证。

## 最紧窗口（Tightest Window）

实例全部配额窗口中已用百分比最大的一扇（平手取重置更近者）。环入图截断、macOS badge 数字（ADR-0020）与自动选例计分（ADR-0016）都取它。

## 主指标 / 次指标（Primary / Secondary Metric）

柱方案的两根条：主指标 = 已用%最高两窗中重置较远的（通常下条），次指标 = 重置较近的（通常上条）。选窗口径（extractMetric/primaryProgressLine）：有 resetsAt 用重置时刻；缺失时按结构化周期 `windowPeriodMs` 外推兜底（ADR-0016 确立口径，GLM 周窗无消耗时不下发 `nextResetTime`，不能因此把主指标错落到短窗）。

## 层（Ring Layer）

嵌套同心环的单个环，映射一扇配额窗口，层数 = min(窗口数, 3)（ADR-0017）。

## 层序（Ring Order）

环层 → 窗口的映射规则：按**重置周期**短→长，外环 = 最短周期窗（如 5h），内环 = 最长周期窗（如月窗）。位置稳定，不随用量波动互换（ADR-0017）。

## 截断（Truncation）

窗口数超过 3 扇时取**最紧三扇**入图，三扇内部仍按层序排位；被挤出的窗继续 tooltip 逐行展示。与柱方案「参与计分但不占柱位」同构（ADR-0016/0017）。

## 托盘方案（Tray Scheme）

托盘图标呈现的可切换、可扩展方案：`default`（静态图标 + 告警换图）/ `usage-ring`（多层嵌套环）/ `usage-bars`（双横向胶囊条）。设置页选择、切换即生效，Rust 侧 tiny-skia 光栅化（ADR-0016/0017）。

## 候选实例（Candidate）

参与托盘计量的实例：刷新成功且至少一条有效配额窗口行；不要求 resetsAt。余额类实例（如 DeepSeek）无窗口出局，仅通过告警影响图标颜色（ADR-0016）。

## 钉选（Pinning）

用户显式指定托盘展示的实例，优先级最高；环/柱方案共用钉选选择器（ADR-0016）。

## 自动选例（Auto Instance Selection）

无钉选时的实例选择规则：置顶分组优先 → 告警中优先 → 最紧窗口% 降序 → 全窗之和降序 → 列表顺序稳定兜底（ADR-0016）。

## 告警强制红（Alert Override）

任一实例处于活跃告警（含余额告警）时，计量图标全部元素强制红色（`#DC2626`）；全局布尔，不区分层级/窗口。档位变色只保留在速览/快速面板内（ADR-0016/0017）。

## glance / 速览面板

托盘左键单击弹出的独立轻量窗口（label `glance`，约 320px，锚定托盘图标，失焦自动隐藏）；内置紧凑行列表与迷你卡片环两种形态（ADR-0016）。

## badge

macOS 菜单栏图标旁的文本标题（`set_title`），语义 = 所选实例最紧窗口的已用百分比（ADR-0020，取代 ADR-0017 的外环语义）：数字回答「离下一次撞限额还有多远」，随最紧窗切换，与图标外环不必对应。Windows/Linux 无此能力；macOS 也无 tooltip，二者互补。

## DPI 档位

托盘图标按主窗口 DPI 绘制的四档尺寸：100%→16px、125%→20px、150%→24px、200%→32px。16px 是设计必须成立的最小战场（ADR-0016/0017）。

## tiny-skia 光栅化

托盘图标在 Rust 侧绘制的技术选型：无文字、零字体依赖。原因：静默启动与关窗驻留下 webview 可能隐藏、canvas 渲染节流不可靠，而托盘必须照常工作（ADR-0016）。
