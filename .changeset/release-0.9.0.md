新增第四家供应商腾讯 WorkBuddy / CodeBuddy，智谱 GLM 提醒增强，速览面板改版，英文界面全量补全，并修复一批显示与稳定性问题。

### 腾讯 WorkBuddy / CodeBuddy（新供应商）

- **积分账务总览**：卡片展示积分总余量与已用百分比、各套餐明细（余量与到期时间，同名套餐自动合并、最紧急的在前）；WorkBuddy 与 CodeBuddy 共用同一账号积分体系，一个供应商即可覆盖
- **统计抽屉**：总览卡、用途分布、模型用量与消耗明细一屏可查
- **每日签到自动完成**：刷新时顺带签到（幂等防重，当日已签不再打扰），到账积分当轮即可见并发通知
- **喵喵旅行托管**：到站自动领奖、空闲自动派出，领奖按行程判重、跨重启不重复提醒；均为不消耗积分的操作，不会动你的资产

### 智谱 GLM

- **重置卡到账提醒**：刷新发现新的可用重置卡立即通知（5 小时卡与周卡合并一条），同一张卡只提醒一次、跨重启依然成立；首次使用只提醒之后新到账的卡，不回放存量；默认开启，无需设置
- **未订阅 Coding Plan 正常降级**：账号没有有效订阅时不再是错误状态——卡片显示「Coding Plan 未订阅」中性说明，余额与重置卡照常查询，统计页以空态呈现
- **告警态托盘提示更完整**：托盘悬停提示处于告警态时仍保留额度摘要，不用点开面板也能看到当前额度状况

### 速览面板改版

- **官方标识**：每行/每张卡前展示供应商官方 logo，即使实例带自定义备注，也能一眼认出是哪家厂商
- **关键信息固定全量展示**：余额、重置倒计时、多窗口配额明细不再需要逐个开关，始终展示；面板形态与展示范围设置恢复纵向布局
- **设置项精简**：告警标记、底部操作条、失焦自动隐藏改为固定开启并移除对应开关，剩余设置重排为双列

### 英文界面补全

- **供应商名称跟随语言**：添加供应商下拉、卡片标题、编辑/删除弹窗、统计抽屉、托盘设置与速览面板中的「智谱 GLM」「腾讯 WorkBuddy / CodeBuddy」等名称，英文界面显示对应英文名
- **卡片数值文案跟随语言**：卡片与速览面板的指标行改为模板化翻译，数值、单位与日期都按当前语言渲染，英文界面不再残留中文
- **切换语言即时生效**：数值文案在渲染时翻译，无需重新刷新数据；历史快照跟随当前语言显示

### 问题修复

- **速览底栏折行**：修复英文界面速览面板底部「通知中心 / 打开主窗口」按钮文字挤成两行的问题
- **网络错误透出真实原因**：供应商查询失败时显示具体原因（DNS 解析失败、连接超时等），不再只报笼统的 "error sending request"
- **柱状图悬停不再残留**：鼠标移开后柱子颜色即时恢复；切换语言不再引起图表整体重建
- **饼图极薄扇区不再消失**：扇区占比极小时间距不再把它吞成缺口，最小扇区仍可见、可读
- **图例标签自适应截断**：图表图例按容器宽度自适应截断省略，图例项少时展示完整名称
