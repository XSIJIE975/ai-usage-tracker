智谱 GLM 卡片回归账户余额展示（ADR-0013，部分取代 ADR-0010）：实测 Coding Plan API Key 可直查余额接口，无需再维护会过期的控制台登录 JWT，凭据保持单 Key 不变。
- **卡片余额行**：刷新时与配额并行拉取账户余额，卡片显示「账户余额」（当前余额口径，与控制台一致）；余额接口失败静默降级为提示消息，不影响配额展示
- **余额明细**：统计抽屉「智谱 GLM」页签新增账户卡片区：当前余额（附可用/冻结）、累计充值、赠送金额、累计消费；开通信用支付的账户额外显示信用余额
- **余额告警**：实例配置新增独立的余额告警阈值（元），与配额百分比阈值并存；余额低于阈值时发送系统通知，告警协调器升级为同一实例多条规则独立边沿触发与冷却
- **数据兼容**：实例表新增余额阈值列，旧库打开时自动补列；余额行随快照落库进入 30 天历史
- **工具用量表修复**：按 2026-09-04 实测修正 `tool-usage` 动态列表字段名（`usageCount`/`totalUsageCount`），同一工具不再重复显示两行（此前固定序列与动态列表拼接、动态行字段名猜测错误恒为 0）；表格只展示调用次数口径并注明官网积分为次数乘单价、接口不提供单价，英文界面优先使用服务端下发的英文工具名
- **重置卡展示**（ADR-0014）：新增智谱「重置卡」通道（官网「用量重置额度」，与配额/余额同一枚 Key 并行拉取）。卡片显示各窗口可用张数摘要；统计抽屉提供「重置管理」弹窗，按官网样式展示每张卡的有效期与可用/已过期/已使用状态，无需再上控制台查看
- **重置卡使用**：统计抽屉内可直接使用可用重置卡（接口规约取自官网前端源码：`POST /biz/customer-package-reset/use`，幂等 requestId 防重复提交）；二次确认弹窗防误触，成功后自动刷新重置卡列表与实例配额；「卡已不可用」错误时提示刷新
- **系统健康度**：统计抽屉 GLM 页签新增健康度卡片（`model-performance-day` 端点，monitor 族同一枚 Key），展示 Max&Pro 与 Lite 高峰期平均 Decode 速度双折线（tokens/s，按日粒度），跟随时间范围切换；取不到数据时整块隐藏
