这一版把「额度到底用了多少」在各处说清楚，并在主窗口头部加了一个主题快捷按钮。

### 速览面板

- **百分比统一为已用**：每扇窗口行都写「已用 X%」，不再出现「积分余量 2%」这种标签与数字方向相反的说法；100% 只在真正耗尽时出现，99.6% 会显示 99%。
- **每扇窗带自己的重置**：5 小时、周、月等窗口各显示自己的重置时刻；接口没给重置时间就整段省略，不写「未知」。环和大号读数改为取最紧窗口，与托盘 badge 同一口径。
- **余额按供应商自己的叫法**：账户余额、Zen 余额、剩余积分不再互相串；WorkBuddy/Qoder 新增独立的「剩余积分」行，Qoder 单池不重复、多池才出跨池合计。
- **状态不再被余额吞掉**：未订阅、已过期、未分配、暂无套餐、不可用即使账号有余额也会显示；MiMo 的「Token Plan 已过期」不再重复主语。
- **WorkBuddy 的积分更好读**：主行改名「积分额度」，最近到期套餐进速览，数字统一千分位（6,106.51）。
- **卡片排版**：环与标题在顶部一行，指标区占满卡片宽度，窗口行保持单行；超长套餐名用省略号并保留 hover 全称，读数、重置和金额不截断。

### 主窗口头部

- **主题快捷切换**：刷新与齿轮之间新增一枚按钮，显示当前模式（跟随系统 / 浅色 / 深色），点击按「跟随系统 → 浅色 → 深色 → 跟随系统」循环；tooltip 会说明当前和下一态。设置抽屉「外观」里的三态选项原样保留，两边同步。
- **顶栏风格统一**：铃铛、刷新、主题、齿轮统一为图标按钮，只有「＋」保留实心品牌样式作为主操作；刷新不再带文字，悬停/读屏给出「刷新 / 刷新中」，刷新中图标旋转。

升级后无需重新配置；速览里的旧快照会在下一次刷新后换成新口径。
