AI Usage Tracker 0.1.0 首个公开发布：一款跨平台桌面应用，助你随时掌握 AI 订阅额度与 API 用量。数据全程仅保存在本机，中文界面，支持浅色 / 深色主题。
- **托盘快速面板**：点击托盘图标即可呼出快速面板，随时查看 OpenCode Go 5 小时 / 本周 / 本月额度与 DeepSeek 余额，无需打开主窗口；关闭主窗口后应用驻留托盘，后台保持运行
- **用量总览**：按供应商分卡片展示额度进度与账户余额，附额度重置倒计时与状态徽标；额度使用超七成时进度条自动转为警示色
- **用量统计**：内置 DeepSeek 与 OpenCode Go 两个统计页签，提供 Token 消耗、请求次数、费用趋势堆叠图、模型用量占比环形图与模型明细表，支持按时间范围、模型、API Key 筛选；OpenCode Go 另可按月翻页查看成本走势与使用历史明细
- **图表体验**：同一模型在所有图表中保持同色，色板随明暗主题自适应；外部图例支持点击筛选与悬停联动高亮
- **凭据管理**：设置页按「通用 / DeepSeek 官方 / OpenCode Go」分页签管理，凭据输入框自带获取教程与配置状态标识，Auth Cookie 粘贴时自动清洗格式
- **本地安全存储**：凭据以 AES-256-GCM 加密保存于本机，加密密钥托管在系统钥匙串（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service），启动即用、全程无需输入密码；用量快照持久化在本地 SQLite 数据库，重启后数据不丢
- **灵活刷新**：全局刷新间隔 5–120 分钟可调，支持按供应商单独关闭自动刷新；手动刷新始终拉取全部供应商，并同步联动统计页
- **应用内自动更新**：启动后自动静默检查新版本，有更新时顶栏出现「新版本」徽标；设置页可查看更新说明、跟踪下载进度，下载完成后自动安装并重启
- **跨平台安装包**：提供 Windows（NSIS 安装包，按用户安装、无需管理员权限）、macOS（DMG）与 Linux（DEB / AppImage）安装包，更新产物均经签名校验
