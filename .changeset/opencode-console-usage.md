OpenCode 已全面切换到新版控制台，这一版重做了它的配置与统计：改用服务 API Key 读取 5 小时/周/月额度，Workspace ID 与 Cookie 改为选填的网页凭据，填了还能看 Zen 余额与请求日志；统计抽屉拆成「概览」「请求日志」两个页签。另修复了速览卡片在英文下被截断、翻面按钮圆角不一致，以及统计页切换区间时短暂显示旧数据的问题。

### OpenCode Go

- **为什么需要重新配置**：OpenCode 已把用量迁到新版控制台，旧页面不再提供数据。本版改为直接读取新控制台，因此每个 OpenCode Go 实例都需要补一个服务 API Key；升级后卡片会提示补充，补上即可恢复。
- **额度改用服务 API Key 读取**：在 OpenCode 控制台生成一个 `oc_sk_...` 服务 Key，填进实例配置就能看到 5 小时、周、月三个额度窗口。Key 无效、账号没有 Go 订阅、调用失败会分别给出提示。
- **Zen 余额与请求日志按需开启**：Workspace ID 与 Cookie 两格都填后，卡片会显示 Zen 余额，统计抽屉会多出请求日志；只填 API Key 也能正常看额度。余额为 `$0.00` 也会显示。
- **余额或日志取不到时不拖累额度**：这两个功能失败不会影响三个额度窗口；余额查询最多等 5 秒，不会拖住卡片；Workspace ID 填错会提示找不到该工作区。
- **旧 Cookie 不用急着删**：之前保存的 auth Cookie 仍可保留，编辑其他配置时也能直接保存。但新版控制台的余额与请求日志需要 `__Host-console_session`：只填了旧 Cookie 时，额度照常，余额与日志会提示重新复制控制台 Cookie。
- **填写位置更清楚**：API Key 放在第一格且必填；Workspace ID 与 Cookie 成对选填，填了其中一个才会要求另一个。提示文案改为指向实例配置，而不是笼统的「设置」。

### 用量统计

- **概览**：三张指标卡（成本、请求次数、Token），按日/按小时的用量柱状图可在成本与 Token 之间切换，下方是按模型拆分的请求数、输入/缓存读写/输出 Token 与成本，成本保留 4 位小数。
- **请求日志**：按时间列出每次推理请求的状态、模型、耗时、Token 与成本；列表只包含模型推理请求，控制台自身的接口调用不会混进来。失败请求的状态标红，缺失的成本或耗时显示「—」而不是 0。支持加载更多，控制台仅保留最近 30 天的日志会在标题下注明。
- **区间更完整**：24 小时、7 天、30 天三档。切换区间时不会再短暂显示上一个区间的数字，加载期间区间选择与筛选条保持可见。
- **数字更准确**：请求日志的 Token 按输入 + 输出统计，推理 Token 已包含在输出里，不再重复相加；缓存读取不会混进单次请求的 Token 合计。
- **刷新更稳**：手动或自动刷新时，请求日志表格保持可见并保留滚动位置；重复加载不会出现重复行，也不会因为翻页状态异常而无限「加载更多」。

### 界面修复

- **速览面板多窗口逐行显示**：卡片里的多窗口额度（如 5 小时/周/月）改为一行一个，英文界面下不再被截断成「M…」。
- **翻面按钮形状一致**：卡片翻到数值面后，右上角按钮的圆角方向不再变化，和百分比面保持一致。
- **图表切换不闪空**：在成本与 Token 之间切换时，图表不会先闪一下空白。
- **英文文案补齐**：统计抽屉、请求日志、配置提示与错误提示的英文翻译已补全。
