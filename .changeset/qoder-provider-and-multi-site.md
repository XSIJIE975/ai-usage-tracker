新增第五家供应商 Qoder（含用量统计），WorkBuddy 接入国际站，两家都按中国站 / 国际站区分。这一版同时收口了凭据填写与校验、统计页时间范围和界面安全策略。

### Qoder（新供应商）

- **订阅与资源包分两行**：同一个账号里的订阅配额、官网按笔发放的资源包各占一行，各自的已用百分比、剩余积分、重置或到期时间分开展示，哪一份用完就为哪一份告警
- **资源包写明最早哪天到期**：单独一行报「余若干 · 某日到期」，只统计还有剩余的包；已经用完的那笔不会再把截止日提前
- **用量统计**：卡片上的「查看统计」可以看近一年每日 Credits 消耗分布、积分消耗趋势（按用途堆叠）、用途分布、模型明细，以及逐条记录（时间 / 用途 / 模型 / 积分 / 官网给出的美元金额），趋势图可切换按积分或按条数看。默认区间近 30 天，自定义最长一年；免费账号同样有完整历史，照常可看
- **未扣积分**：统计概览里的这一格是折前合计减去实际扣减，官网活动折扣和免费调用都算在里面；明细中未计费的记录会标出「未计费」
- **凭据只有一格**：粘贴 `qoder_session_cookie` 的值即可，键名与请求头由程序补全
- **数据来自网页接口**：Qoder 未对个人账号开放用量 API，数据取自账号控制台的网页接口，官方改版可能失效；届时界面会给出明确报错，不会静默显示错误的数字

### WorkBuddy / CodeBuddy

- **接入国际站**：workbuddy.ai 的账号也能添加了，积分账务与用量统计和中国站一致；每日签到、连续登录与喵喵旅行是中国站独有的玩法，国际站没有
- **凭据改为三格填写**：`session`、`session_2`、`User-Agent` 各贴值本身，不必再粘整串 cURL；三项必须来自同一条请求，「测试」按钮移到三格之后，一次测完

### 多站点

- **添加时选站点**：Qoder 与 WorkBuddy 都分中国站与国际站，两套登录域互不通用，换站后需要重贴该站的凭据
- **一眼看出是哪一站**：主窗口卡片、速览面板的行与卡、统计页标题都会在供应商标识旁标注「中国站 / 国际站」，同一家两张卡片分得开；弹窗里获取凭据的指引也跟着所选站点切换

### 配置弹窗

- **缺什么直接说**：凭据项漏填不再让保存——必填的那几格前面标了红色 `*`，空着的格子下面会出现一句红字，光标自动跳到第一个待补的地方
- **贴错了当场指出**：把 `Cookie:` 前缀或键名一起贴进来、值里混进分号空格换行中文，都会在保存前就提示该怎么贴；以前这些要等到刷新失败才暴露，而且看不出原因
- **可选项写清了留空的后果**：需要额外凭据才能开启的功能，格子下面会直接说明不填会怎样——DeepSeek 的 UserToken 只有用量统计页用得上，留空不影响余额查询；OpenCode Go 的 API Key 留空时按控制台页面取用量，填了则走官方用量接口

### 用量统计页

- **时间范围按各家实际情况给**：Qoder 可选到一年，其余供应商仍是 30 天上限，行为与之前一致
- **日期没填好会告诉你**：把开始或结束日期清空时，界面直接写明「请填写完整的开始与结束日期」，不再一直转圈不给原因
- **取不全就报错**：统计明细如果没能取完区间内的全部记录，会明确说明取了多少、为什么停下，而不是拿半份数据画出看起来正常的图表

### 界面与文案

- **英文界面的时长文案**：重置倒计时与刷新间隔不再出现「1 days」这类单复数错误，改用 `1d 16h to reset`、`30 min` 这种紧凑写法，窄面板里也不会撑开
- **没有额度时说明原因**：账号没有可显示的额度时（Qoder 未分配积分、WorkBuddy 没有有效套餐），主窗口卡片与速览面板给出同一句具体说明，而不是笼统的「暂无数据」

### 凭据与界面安全

- **凭据只发给对应供应商**：你贴的 Key 与 Cookie 只会被送进这家的官方站点；发往其他域名（包括另一家供应商的）的请求一律不发，并当场说明原因。全程只走加密连接，中途被转到不加密地址也会立刻停下
- **请求头由程序补全**：Cookie、Authorization、User-Agent 都按各家要求统一拼装，就算你把整行请求头一起贴进输入框，也不会多出一份互相冲突的凭据头让服务端读到错的那个
- **界面加了内容安全策略**：发布版给界面上了 CSP——只加载程序自己的脚本，界面也无法向外部地址发请求；图表提示框里显示的模型名、用途名一律按纯文本处理。取数都在程序侧完成，功能不受影响
