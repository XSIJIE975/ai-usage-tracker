# 供应商卡片翻卡与快速面板体验修复

## ✨ 新增

- **供应商卡片翻卡查看积分原值**：智谱 GLM Coding Plan 卡片右上角新增翻面按钮，点击后整卡 3D 翻转，以原始数值展示配额（已用 / 剩余积分），再点翻回百分比视图。翻面朝向每张卡片独立，拖拽排序时浮起的卡片也会保持当前朝向。

## 🛠 修复

- **快速面板自动刷新真正生效**：此前倒计时归零后并不会刷新数据（倒计时只是展示），现在倒计时归零会真实执行一轮刷新并重新计时。
- **拖动面板不再误触发刷新**：此前每次拖动快速面板都会触发一轮刷新、倒计时被重置，现在拖动不再打扰刷新节奏。
- **刷新过程可见反馈**：自动刷新与呼出刷新进行中，顶栏和各卡片右上角的刷新按钮会联动旋转，状态条同步显示「刷新中」，不再只能靠更新时间变化才能察觉。
- **统计抽屉不再串数据**：同一供应商添加多个实例（如主账号 + 体验账号）时，各自的「查看统计」此前都会显示第一个实例的数据，现按实例各自取数。

## 🎯 优化

- **快速面板通知中心**：高度改为随内容自适应（有上限、超出内部滚动），空状态不再撑满整个面板。
