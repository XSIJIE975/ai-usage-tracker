托盘速览全面改版，智谱 GLM 账户管理能力增强，新增开机自启支持。

### 托盘速览改版

- **速览面板**：托盘左键单击弹出全新速览面板，锚定在托盘图标旁，再点或失焦自动收起；提供紧凑行列表与迷你卡片两种展示形态，面板顶栏一键切换并记忆选择
- **托盘图标方案**：图标形态可在「默认图标」「环形计量」「条形计量」间切换——环形计量以进度环展示用量最高的配额窗口；条形计量以双横条展示 5 小时额度与周配额的用量，若服务商还提供更多配额窗口（如月度额度），则展示其中用量最高的两个；默认静态品牌色，仅告警时变红
- **自动选例**：图标优先展示置顶实例，其次按告警状态与各窗口用量自动选出最需要关注的实例；也可以固定展示某个实例
- **动态托盘提示**：悬停图标即可查看当前实例各配额窗口的已用百分比；macOS 同时在菜单栏图标旁显示数字
- **快速面板收敛**：快速面板改为全局快捷键或托盘右键菜单唤起，右键菜单保持「打开主窗口 / 显示快速面板 / 退出」
- **设置页**：「托盘图标」与「速览面板」两张设置卡支持方案实时预览、展示范围勾选（全部 / 自选实例）与展示字段开关

### 智谱 GLM

- **账户余额**：实例卡片回归余额展示，与配额并行刷新；统计抽屉新增余额明细（当前余额、累计充值、赠送金额、累计消费、信用余额）；支持独立的余额告警阈值，余额不足时发送系统通知
- **重置卡**：展示各配额窗口的可用重置卡，统计抽屉提供「重置管理」弹窗查看每张卡的有效期与状态，并可直接使用重置卡（二次确认防误触，成功后自动刷新配额）
- **系统健康度**：统计抽屉新增健康度卡片，展示 Max&Pro 与 Lite 高峰期平均 Decode 速度双折线（按日粒度，跟随时间范围切换）
- **工具用量**：修复同一工具重复显示两行的问题，现统一展示调用次数口径

### 启动

- **开机自启**：随系统登录自动运行并驻留系统托盘（Windows / macOS / Linux），卸载时自动清理注册；注册失败时明确提示且不保存设置
- **静默启动**：开机自启的子选项，自启时不显示主窗口、仅在托盘运行；手动启动与日常使用不受影响

### 修复

- 修复从旧版本升级后快速面板唤醒快捷键失效的问题：设置读取时对缺失配置项自动补齐默认值
